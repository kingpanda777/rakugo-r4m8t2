# 落語ログ

聴いた落語を記録して、同じ演目を演者違いで比べるためのアプリです。

## 使ってみる

`index.html` をダブルクリックすると、ブラウザで開きます。
（フォルダは `C:\Users\merle\rakugo-log`）

インターネットにはつながっていなくても動きます。

## 画面

| | |
|---|---|
| **一覧** | 上のタブで「演目で見る」「演者で見る」を切り替えます。最近聴いたものが上に来ます |
| **記録する** | 演目・演者・日付・視聴方法・評価・印象タグ・メモを入れて保存します |
| **集計** | よく聴いた演目、演者別の回数、印象タグの割合、月別の推移、視聴方法別 |

演目名や演者名は、2回目からは入力欄をタップすると候補が出ます。

### 記録の直し方・消し方

記録カードの下にある「編集」「削除」から。
演目のあらすじは演目のページ、演者の写真・代数・メモは演者のページで直せます。

### 演目名・演者名を書き間違えたとき

**演目のページ（または演者のページ）の「編集」から直すのが基本です。**
名前を直しても、その演目・演者に付いている記録はすべてそのまま付いてきます。

記録の「編集」画面で演目名・演者名を書き換えたときは、保存を押すと
どちらのつもりか聞かれます。

| 選択肢 | どうなるか |
|---|---|
| 〜の名前を直す | その演目・演者の名前が変わり、**記録すべてに反映されます** |
| 別の〜として分ける | 新しい演目・演者ができて、**その記録1件だけ**が移ります |

「この記録、実は別の人だった」というときは下、「名前を打ち間違えていた」
というときは上を選んでください。

### 同じものが2つに分かれてしまったとき

「お茶くみ」と「お茶汲み」のように同じ演目が二重にできてしまった場合は、
**消したいほうの演目のページを開き、「演目名・あらすじを編集」で
残したいほうと同じ名前に書き換えて保存**してください。
「2つを1つにまとめますか？」と聞かれるので、はいを選ぶと記録がまとめられます。

演者も同じで、「名前＋代数」を残したいほうと同じにすると、まとめるか聞かれます。
あらすじ・写真・メモは残るほうが優先され、残るほうが空のときだけ引き継がれます。

### 印象タグ

「笑える／しんみり／こわい／お見事／バカバカしい／眠くなった」から**3つまで**。
3つ選ぶと、残りのボタンは薄くなって押せなくなります。

### 評価

星を押すと1〜5、**同じ星をもう一度押すと「評価なし」に戻ります**。

## データの置き場所について

**記録はこの端末のブラウザの中だけに保存されます。** どこにも送信されません。

そのため、次の場合は記録が消えます。気をつけてください。

- ブラウザの「閲覧履歴データの削除」で、サイトデータ（Cookie など）も一緒に消したとき
- 別の端末や別のブラウザで開いたとき（そちらは空の状態から始まります）
- プライベートブラウズ（シークレットウィンドウ）で開いたとき
  → この場合は画面の上に赤い帯が出ます

演者の写真も端末の中だけです。GitHub には上がりません。
